# 100 Video Fakta Hewan

Aplikasi web statis (satu file `index.html`) berisi paket produksi untuk 100 video Shorts: prompt gambar, naskah voice over, teks layar, judul, deskripsi, hashtag, thumbnail, dan checklist. Progres tersimpan di browser (localStorage).

## Cara pasang di GitHub Pages (tanpa coding)
1. Buka github.com dan login, lalu klik **New repository**. Beri nama, misalnya `animal-100`, pilih **Public**, klik **Create repository**.
2. Klik **uploading an existing file**, tarik file `index.html` dan `README.md`, lalu klik **Commit changes**.
3. Buka **Settings**, lalu **Pages**. Di bagian Source pilih **Deploy from a branch**, branch `main`, folder `/ (root)`, lalu **Save**.
4. Tunggu 1 sampai 2 menit. Alamatnya: `https://NAMA-GITHUB-KAMU.github.io/animal-100/`

Progres centang tersimpan per browser dan per perangkat.

## Alur tiap video
1. Buat 3 sampai 4 gambar dari prompt gambar memakai generator gambar AI.
2. Salin naskah ke CapCut (Teks, lalu Teks ke audio, suara bahasa Inggris).
3. Susun gambar, tambahkan teks layar, lalu ekspor 9:16.
4. Upload dengan judul dan deskripsi dari aplikasi. Jika memakai gambar atau suara AI yang tampak nyata, pilih Ya pada "konten yang dimodifikasi".
5. Centang langkah di aplikasi.

## Catatan
- Fakta ditulis dari pengetahuan umum. Cek ulang fakta yang kamu ragukan sebelum upload.
- Naskah sekitar 20 sampai 25 detik. Untuk 30 sampai 45 detik, tambah jeda visual atau satu fakta tambahan.
- Hindari 100 video yang terasa identik. YouTube bisa menilai konten massal berpola sama sebagai tidak orisinal, jadi variasikan visual dan gaya narasimu.
